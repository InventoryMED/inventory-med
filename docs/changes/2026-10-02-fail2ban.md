# Proteção de autenticação com Fail2ban

**Data:** 2026-10-02
**Responsável:** Gabriel Pereira
**Status:** concluída

## Resumo

O Fail2ban foi instalado e habilitado para observar as tentativas de autenticação do
SSH e bloquear temporariamente origens que excedam o limite configurado.

## Motivo

Adicionar uma segunda camada de proteção contra tentativas automatizadas e repetidas de
acesso ao servidor.

## Comandos executados na VPS

```bash
sudo apt update
sudo apt install -y fail2ban
sudo nano /etc/fail2ban/jail.d/inventorymed.conf
sudo fail2ban-client -t
sudo systemctl enable --now fail2ban
sudo systemctl restart fail2ban
sudo fail2ban-client status
sudo fail2ban-client status sshd
```

## Serviços afetados

- `fail2ban`: instalado, habilitado e iniciado.

## Validação

- configuração validada pelo cliente do Fail2ban;
- serviço habilitado e iniciado sem erro informado;
- cadeia de proteção do `sshd` consultada após a inicialização.

## Recuperação

Para interromper a proteção sem remover o pacote:

```bash
sudo systemctl disable --now fail2ban
```

Antes de reativar, corrigir a configuração e executar `sudo fail2ban-client -t`.
